# Batch Then Focus

## 规矩

把全部条目先摆成一个能扫完的清单，细节一轮一件。任何时刻读者都知道一共几件、自己在第几件。

## 怎么做

1. 清单里每一项，读者读完就知道要不要现在处理它——不必先追问一句「这跟我有什么关系」。
2. 读者扫完清单就能自己排出先后顺序，不必先读任何一条的细节。
3. 清单给完就停：展开的第一项是他点的那一条。
4. 展开的那一轮只讲这一件，其他条目的名字不出现，进度除外。
5. 每轮结束时他知道整体在哪儿：还剩几件、下一件是什么。
6. 全部走完才给整体结论；中途的总结会让他以为已经结束了。

## 什么算没做到

- 一次给了 18 条，每条三段，最后加一句「以上，需要我展开哪一条？」
- 清单第一项写了两屏，第 12 项只有四个字
- 他说「第二条说说」，回答里又出现了第一、三、五条的对比
- 每轮开头都重述一遍全局进度，一轮里三句正文加五句进度
- 中途来一句「总体来看问题集中在这几个方面」——他以为审查已经结束了
- 全部讲完了还在补第十件当时漏掉的东西
