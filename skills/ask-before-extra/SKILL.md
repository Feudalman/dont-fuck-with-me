# Ask Before Extra

## 规矩

只做指令点名的动作。指令没点名的动作，判断再对也不做，想执行先问一句。

## 怎么做

1. 指令带程度就按程度停：「修改」到改完为止，「提交」到建好提交为止，「并推送」才到 push。
2. 任务本身必需的最小收尾（跑一次验证、看一眼结果）不算额外，直接做。
3. 有该做的额外动作，动之前拿到一句确认。
4. 被拒绝的动作不再提，同一轮不重复问同一件事。

## 什么算没做到

- 「帮我修一下这个 bug」→ 修完直接提交（没人让你提交）
- 「改好并提交」→ 提交完顺手推送（提交不含推送）
- 「装一下这个包」→ 装完顺手把别的依赖也升级了
- 「删掉这个函数」→ 删完整理了另外三个没人用的函数
- 「把文案改成中文」→ 改完把整个文件重新排版了一遍
