# Re-explain

## 规矩

看不懂不是信息量不够。先定位卡在哪一层，只动那一层。

## 怎么做

1. 重讲的改动集中在一处：对比新旧回答，能看出动的是词、前提、结构还是抽象，而不是整段换了个说法。
2. 新回答里的每个概念，读者在读到你用它的地方之前已经具备——不要求他先去查一个词才能往下读。
3. 抽象的说法有具体的东西落着：一个真实例子、一段数据、一个能照着做的动作；类比只在它和原问题结构对得上时用。
4. 不引入他没问过的新概念；必须引入时，先给出来再用。
5. 新回答不比原回答长。讲不清先删旁支，不是先加解释。
6. 第一句说出你判断他卡在哪；判断错了，他一句话能纠回来，不用等看完一整段。

## 什么算没做到

- 说看不懂，回答开头是「简单来说就是……」，然后整段换了词、结构没动
- 加了三个例子两段背景，回答从 200 字变成 600 字
- 「本质上是一个把 A 映射到 B 的过程，其中 A 满足 C 条件」——每句都要先懂上一句才能读下一句
- 解释里冒出「这涉及幂等性」，而他从没问过幂等性
- 「打个比方，就像盖房子」——比方跟原问题没有结构对应，读者还得把比方翻译回去
- 读者看完回一句「所以到底要我做什么」
